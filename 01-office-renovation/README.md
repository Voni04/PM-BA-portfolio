# Office Renovation Project

## Project Overview

This is a self-directed Project Management portfolio project simulating the planning and coordination of an office renovation for approximately 25 employees.

**Role:** Project Coordinator  
**Target Duration:** 8 Weeks  
**Budget:** LKR 4,000,000  
**Tools:** GanttProject, Google Sheets, Google Docs

## Project Objective

Plan and coordinate the renovation of an office within the approved budget and target schedule while managing project activities, resources, costs and risks.

## Work Completed

- Developed a Project Charter defining scope, objectives, stakeholders, constraints and deliverables.
- Created a Work Breakdown Structure (WBS) covering planning, procurement, renovation, installation, testing and handover.
- Developed a detailed Gantt schedule with task durations and dependencies.
- Identified parallel activities and created a final project handover milestone.
- Assigned project resources to scheduled activities.
- Reviewed resource allocation using the Resource Chart.
- Performed Critical Path Analysis to identify schedule-sensitive activities.
- Created a project Budget Tracker comparing planned and actual costs.
- Performed cost variance and budget utilization analysis.
- Created a Risk Register using probability and impact assessment.
- Assigned mitigation actions and risk owners.

## Results

- Planned Budget: LKR 4,000,000
- Simulated Actual Cost: LKR 3,850,000
- Budget Variance: LKR 150,000 under budget
- Budget Utilization: 96.25%
- Detailed Schedule: 14 October 2026 – 14 December 2026

The detailed schedule slightly exceeded the original eight-week target, demonstrating how detailed scheduling can identify variance from an initial project target.
