# Bakery Branch Expansion Project

## Project Overview

This is a self-directed Project Management portfolio project simulating the coordination of a new bakery branch opening.

**Role:** Project Coordinator  
**Target Duration:** 6 Weeks  
**Original Budget:** LKR 5,000,000  
**Tools:** Trello, Google Sheets, Google Docs

## Project Objective

Plan and coordinate the activities required to open a new bakery branch within the target schedule and budget while managing tasks, risks, issues and project changes.

## Project Scope

The project included:

- Branch requirements and shop layout
- Renovation work
- Bakery equipment procurement
- Furniture procurement
- Electricity and utilities
- POS and IT setup
- Staff recruitment
- Staff training
- Final inspection and branch opening

## Work Completed

- Created a Trello board to track project activities.
- Organized tasks using To Do, In Progress, Waiting / Blocked and Completed statuses.
- Used cards, checklists, labels and due dates to manage project work.
- Created a project budget tracker in Google Sheets.
- Created a Risk Register to identify and manage project risks.
- Distinguished between project risks and issues.
- Simulated a seven-day bakery equipment delivery delay.
- Assessed the impact of the supplier delay on the project.
- Evaluated an alternative procurement option.
- Identified an additional LKR 250,000 equipment cost.
- Prepared a formal Change Request for the additional cost.
- Simulated sponsor approval of the Change Request.
- Updated the revised project budget after approval.

## Project Issue & Change

During the simulated project, the bakery equipment supplier reported a seven-day delivery delay.

An alternative procurement option was evaluated to reduce the risk of delaying the branch opening. The alternative increased the equipment cost by LKR 250,000.

A Change Request (CR-01) was prepared to assess the impact and obtain approval before proceeding.

**Original Project Budget:** LKR 5,000,000  
**Revised Project Budget:** LKR 5,250,000  
**Approved Increase:** LKR 250,000  
**Change Request:** CR-01  
**Decision:** Approved

This demonstrated the change control process:

Problem Identified → Impact Assessed → Alternative Considered → Change Documented → Approval Obtained → Project Information Updated
