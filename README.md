# Project Management & Business Analysis Portfolio

I am a third-year Information Technology undergraduate with an interest in Project Management and Business Analysis. This portfolio includes self-directed projects designed to build practical experience in project planning, scheduling, requirements analysis, Agile/Scrum, risk management, budget tracking, and change management.

## Projects

### 1. Office Renovation Project
**Focus:** Traditional Project Management  
**Tools:** GanttProject, Google Sheets, Google Docs

Developed an end-to-end project management plan for a simulated LKR 4 million office renovation. The project included a Project Charter, Work Breakdown Structure (WBS), Gantt schedule, task dependencies, resource allocation, critical path analysis, budget tracking and risk management.

**Skills:** Project Planning, WBS, Scheduling, Critical Path Analysis, Resource Planning, Budget Management, Risk Management

---

### 2. Bakery Online Ordering Website
**Focus:** Agile Project Management & Business Analysis  
**Tools:** Jira, Google Docs

Translated business requirements for a simulated bakery online ordering website into Epics, User Stories and Acceptance Criteria. Created a Product Backlog, performed Sprint Planning, tracked work through a Scrum board, documented a defect and simulated User Acceptance Testing (UAT).

**Skills:** Requirements Analysis, Agile, Scrum, Epics, User Stories, Acceptance Criteria, Product Backlog, Sprint Planning, Bug Tracking, UAT

---

### 3. Bakery Branch Expansion Project
**Focus:** Project Coordination, Budget, Risk & Change Management  
**Tools:** Trello, Google Sheets, Google Docs

Coordinated a simulated bakery branch expansion project using Trello. Tracked project activities, documented risks and issues, analysed a LKR 250,000 equipment cost increase and prepared a Change Request to assess and approve the revised project budget.

**Skills:** Task Tracking, Kanban, Budget Management, Risk Management, Issue Management, Change Control
