# Bakery Online Ordering Website

## Project Overview

This is a self-directed Business Analysis and Agile Project Management portfolio project simulating the planning and requirements management of an online ordering website for a bakery.

**Role:** Business Analyst / Project Coordinator  
**Methodology:** Agile / Scrum  
**Main Tool:** Jira

## Project Objective

Define and manage business and user requirements for a bakery online ordering website using Agile practices and Jira.

The proposed system allows customers to create accounts, browse bakery products, view product details, manage a shopping cart and place orders.

## Work Completed

- Identified the business problem, project objective and key stakeholders.
- Defined high-level system requirements.
- Created Epics to organize major areas of functionality.
- Converted requirements into User Stories.
- Defined Acceptance Criteria for User Stories.
- Created and organized a Product Backlog in Jira.
- Selected User Stories for Sprint 1 through Sprint Planning.
- Defined a Sprint Goal and started the Sprint.
- Tracked work using a Scrum Board with To Do, In Progress and Done statuses.
- Created and tracked a software defect using a Jira Bug.
- Simulated resolution and retesting of the identified defect.
- Performed simulated User Acceptance Testing (UAT) against Acceptance Criteria.
- Completed the Sprint after the planned work was finished.

## Agile Structure

Examples of Epics used in the project included:

- Customer Account
- Product Catalogue
- Shopping Cart & Checkout
- Order Management
- Admin Management

Example User Story:

> As a new customer, I want to create an account so that I can place orders and access my order information.

Acceptance Criteria were defined to specify the conditions required for the story to be accepted.
